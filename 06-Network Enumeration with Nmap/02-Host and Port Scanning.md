HTB Academy — Nmap: TCP Port Scanning & Host Enumeration

In this hands-on exercise, I practiced network enumeration using Nmap to identify open TCP ports and discover the target system's hostname. I explored TCP SYN scanning, full-port scanning, service detection, and SMB-based host identification.

This exercise strengthened my understanding of network reconnaissance, attack surface discovery, and the importance of accurate enumeration during penetration testing.

Tools: Nmap, Linux Terminal
Skills: TCP Scanning, Network Enumeration, Host Discovery, Service Identification
